# PromQL Exercises

Try these without looking at the solution first.

## Exercise 1 — Targets

Show all Prometheus targets.

## Exercise 2 — Down Targets

Show only targets whose `up` value is `0`.

## Exercise 3 — Memory

Calculate memory utilization as a percentage.

## Exercise 4 — CPU

Calculate CPU utilization per instance.

## Exercise 5 — Container CPU

Find the top 5 containers by CPU.

## Exercise 6 — Container Memory

Find the top 5 containers by memory.

## Exercise 7 — Network

Calculate container receive traffic per second.

## Exercise 8 — Histogram

Calculate P95 request latency.

## Exercise 9 — Aggregation

Show the number of targets per job.

## Exercise 10 — Challenge

Create one query that shows the busiest container by CPU.
